# ADRES / agentka nieruchomości

Gotowa strona HTML/CSS/JavaScript. Wgraj całą zawartość `dist` do głównego katalogu repozytorium GitHub Pages. Zachowaj folder `assets`. Nie potrzeba instalacji ani kompilacji.

Parallax, sticky prezentacja wnętrz sterowana przewijaniem, cztery rozdziały i suwak dostępny klawiaturą. Przy ograniczeniu ruchu prezentacja staje się zwykłą sekcją obsługiwaną suwakiem. Oferty mają filtry typu i ceny, sortowanie oraz galerie. Formularz przygotowuje lokalne podsumowanie, nie wysyła danych i nie rezerwuje wizyty.

Fikcyjna marka ADRES i postać Anny Radeckiej. Oferty, parametry, ceny oraz lokalizacje są przykładowe. Zdjęcia ilustracyjne nie są dokumentacją nieruchomości na sprzedaż. Prezentacja wnętrz to moodboard, nie spacer 3D konkretnego lokalu.
